# Code of Conduct

Build a CubeSat has one code of conduct for all of its repositories, the BAC Discord server and its events: the [BAC Code of Conduct](https://bac.page/conduct), adapted from Contributor Covenant 3.0.

To report a possible violation, write to conduct@buildacubesat.space. If the report concerns one of the two conduct contacts, the code says how to reach the other one directly (§6).
