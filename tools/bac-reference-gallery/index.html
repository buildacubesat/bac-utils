Source of truth

The gallery is implemented against the BAC Identity Guide, the BAC Interface Design Guide and the BAC Project & Tooling Guide. Canonical values live in those guides; css/tokens.css is their executable copy and the stylesheet other BAC surfaces take their values from. If a page disagrees with a guide, the guide wins.

Engineering values on the pages are labelled as examples and are not project status records.
