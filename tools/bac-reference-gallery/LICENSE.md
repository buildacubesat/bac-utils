# Licensing

The BAC reference gallery follows the Build a CubeSat licensing split:

| Part | License |
| :-- | :-- |
| Renderer software: `src/`, `tests/`, `pyproject.toml` | MIT (the repository's `LICENSE`) |
| Documentation: the HTML pages, the CSS stylesheets including `css/tokens.css`, the SVG illustrations, `README.md`, `REFERENCE-MAP.md` and the rendered PNG and PDF exports | CC BY-SA 4.0 |

The canonical BAC guides remain authoritative for project-wide licensing conventions.
