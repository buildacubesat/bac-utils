# Licensing

The Build a CubeSat (BAC) reference gallery follows the project's licensing split – software MIT, documentation CC BY-SA 4.0 – with the stylesheets under both, so that software can take its values from `tokens.css`:

| Part | License |
| :-- | :-- |
| Renderer software: `src/`, `tests/`, `pyproject.toml` | MIT |
| Stylesheets: `css/tokens.css`, `css/gallery.css`, `css/index.css` | MIT or CC BY-SA 4.0, at your option (`SPDX-License-Identifier: MIT OR CC-BY-SA-4.0` in each file) |
| Documentation: the HTML pages, the SVG illustrations, `README.md`, `REFERENCE-MAP.md` and the rendered PNG and PDF exports | CC BY-SA 4.0 |
| Brand marks: `assets/bac-symbol.svg`, the Build a CubeSat name and wordmark wherever they appear in the pages and exports | Not licensed – BAC Marks of nihil.space GmbH, see the BAC Trademark Policy |

CC BY-SA 4.0 is the Creative Commons Attribution-ShareAlike 4.0 International license: https://creativecommons.org/licenses/by-sa/4.0/legalcode. The MIT text, the same as the repository's `LICENSE`, follows so that it travels with the installed package.

The Build a CubeSat name and logo are not covered by this gallery's licences; see the BAC Trademark Policy (nihil.space GmbH, hello@buildacubesat.space). The canonical BAC guides remain authoritative for project-wide licensing conventions.
